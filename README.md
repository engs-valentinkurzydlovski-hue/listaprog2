# Algoritmos de Ordenação em C++

Implementação de cinco algoritmos de ordenação em C++.

## Vetor de teste

`{5, 3, 8, 4, 2}`

Resultado esperado: `{2, 3, 4, 5, 8}`.

## Arquivos

- `bubble_sort.cpp`
- `selection_sort.cpp`
- `insertion_sort.cpp`
- `merge_sort.cpp`
- `quick_sort.cpp`

## Critérios de contagem

- Comparações: comparações entre valores do vetor.
- Trocas: trocas efetivas entre posições diferentes.
- Insertion Sort: informa deslocamentos separadamente, pois não usa trocas diretas nesta implementação.
- Merge Sort: informa gravações no vetor original separadamente, pois intercala por cópias.
